# AI Knowledge Assistant using RAG

An AI-powered document assistant built with Python, FastAPI, LangChain, ChromaDB, and OpenAI.

## Features

- Upload PDFs
- Semantic Search
- Retrieval Augmented Generation (RAG)
- Conversational Question Answering
- Source Citations
- FastAPI Backend
- Streamlit Frontend

## Tech Stack

- Python
- FastAPI
- LangChain
- ChromaDB
- OpenAI
- Sentence Transformers
- Streamlit
- uv
- Docker
